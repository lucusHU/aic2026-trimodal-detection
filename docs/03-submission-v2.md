## 一、项目简介

本项目在 **D-FINE-HGNetv2-L** 检测器基础上，构建 **RGB + 红外 + 深度 三模态目标检测方案**：

- **输入**：5 通道 `[RGB(3) | Infrared(1) | Depth(1)]`，三模态按文件名严格对齐
- **融合方式**：在 backbone 的 **P3 / P4 / P5** 三处插入「零初始化门控残差」融合模块
- **推理**：单权重多尺度 TTA（800 / 1024 / 1088）+ 统一 NMS

核心思路：以官方提供的三模态训练集微调，并在推理侧充分利用 **高于训练尺度带上限（992）的分辨率**，
换取小目标收益。

## 二、模型结构

### 2.1 三模态融合模块

```
backbone (HGNetv2, RGB 3ch)  ──feats──►  P3 / P4 / P5
                                              │
a = [Infrared | Depth] (2ch)                  │
  └─ CBR stem (width=32, strides /2,/4,/8,/16,/32) ─► a3 / a4 / a5
                                              │
        f' = f + ZeroConv(a) · 2·sigmoid(Gate(a))     ← 融合公式
                                              │
                                          HybridEncoder ─► DFINETransformer ─► 检测头
```

其中 `ZeroConv`（proj）与 `Gate` 卷积**全部零初始化**，因此加载 RGB 权重后
`f' ≡ f` —— **第 0 步与纯 RGB 模型数学等价**。该性质已实测验证：

| 输入 | mAP |
|---|---|
| 5 通道（走 tri 分支） | 0.5641 |
| 3 通道（走 RGB 回退分支） | 0.5641 |

两者严格相等，且 `fuse.*.proj.weight/bias` 的 absmax **精确为 0**。

### 2.2 关键参数

| 项 | 值 |
|---|---|
| 模型 | D-FINE-HGNetv2-L |
| 参数量 | 30,671,835（RGB 主干）+ 约 1.31M（新增 aux/fuse 支路） |
| hidden_dim / num_queries / num_layers | 256 / 300 / 6 |
| aux 支路宽度 | 32 |
| 输入通道 | 5（RGB 3 + IR 1 + Depth 1） |
| 预训练权重 | `dfine_l_obj365.pth`（Objects365，赛事明文允许） |
| 热启动权重 | `output/seed1_800/best_stg2.pth` 的 **EMA 分支**（RGB 单模态已训模型） |
| 最终权重 | `output/tri_final3/best_stg1.pth` |

## 三、训练配置

配置文件：`configs/tri_final3.yml`

| 项 | 值 |
|---|---|
| 数据 | 官方三模态训练集；train 1700 / val 300（官方划分） |

| 优化器 | AdamW，分参数组：backbone `5e-6` / enc+dec 含 norm 层 `3e-5` / **aux+fuse 支路 `5e-3`** |
| 增强 | RandomZoomOut / RandomIoUCrop(p=0.8) / RandomHorizontalFlip / Resize |
| EMA | 启用 |

## 四、推理配置（提交包生成方式）

```bash
python infer_tri.py \
  -c configs/tri_final3.yml \
  -r output/tri_final3/best_stg1.pth \
  -i dataset/data/AIC2026_PHASE_2_1000/visible \
  --aux dataset/data/AIC2026_PHASE_2_1000/infrared \
        dataset/data/AIC2026_PHASE_2_1000/depth \
  --size 800 1024 1088 --nms-iou 0.7 --max-det 100 --conf 0.001
# 随后 clamp + 合规校验
python fix_submit_any.py zip/tri3_scales_800_1024_1088.zip \
                        zip/tri3_scales_800_1024_1088_fixed.zip
```

### 4.1 多尺度 TTA

三个尺度分别前向，预测框合并后统一 NMS（IoU 0.7），按置信度保留每图前 100 框。
**这是同一权重、同一模型的推理增强，不涉及任何多模型集成。**

### 4.2 测试集模态格式（重要，容易踩坑）

测试集 depth **格式混合**，必须区别处理，否则辅助通道完全 OOD 且不会报错：

| | 数量 | 格式 | 处理 |
|---|---|---|---|
| `.png` | 883 | uint16，0~19999 毫米 | **除以 80 再 clip 到 [0,255]** |
| `.jpg` | 117 | uint8，0~255（已量化） | 直接使用 |

infrared 1000 张均为三通道，取第 0 通道。

### 4.3 坐标合法性

多尺度合并后重新归一化会产生越界框。出包时统一执行
`cxcywh → xyxy → clamp[0,1] → 转回 cxcywh`，本次共修正 **4091 个框，丢弃 0 个**。

## 五、性能

所有数字均为 **val 300（官方训练集划分的验证集）** 上的 mAP@0.5:0.95，pycocotools 口径
（`maxDets=[1,10,100]`，conf 0.001，NMS 0.7）。

| 配置 | mAP | AP50 | AP75 | APs | APm | APl |
|---|---|---|---|---|---|---|
| RGB 单模态 @800+928（上一版提交） | 0.5670 | 0.8391 | 0.6094 | 0.3053 | 0.4507 | 0.7247 |
| RGB 单模态 @800+1024+1088 | 0.5752 | 0.8495 | 0.6259 | 0.3365 | 0.4597 | 0.7282 |
| **三模态 @800+1024+1088（本版提交）** | **0.5778** | — | — | — | — | — |

### ⚠️ 增益归因（必须如实拆分）

**+1.08pp 的来源必须拆成两半：**

| 来源 | 增益 | 说明 |
|---|---|---|
| **推理尺度策略**（800+928 → 800+1024+1088，同一权重） | **+0.82pp** | 5 个含 1024+ 的尺度组合同向；20 次随机折半中 19 次为正 |
| **三模态模型本身**（同尺度下 RGB→三模态） | **+0.26pp** | **落在 val300 的 ±1.6pp 噪声内，不显著** |

⇒ **本方案的主要增益来自推理尺度策略；多模态融合的贡献不显著。**

### ⚠️ 消融证据（诚实披露）

把 infrared 或 depth 整通道置 0 后重新评测，mAP 与完整 5 通道输入**完全相同**（0.5678 / 0.5678 / 0.5678）。
逐权重检查显示融合支路的 `proj` 权重在 14 epoch 后仅从 0 移动到 std≈0.002，
残差注入强度约 0.2%~2%，不足以改变 top-100 框的选择。

**即：本版交付的是「真三模态输入 + 单模型」，但辅助模态目前未产生可测量的增益。**

### ⚠️ 榜单预期

我们目前唯一的外部锚点是：val 0.5670 的 RGB@800+928 包在复赛榜单得 **50 分**。
基于此，本版的合理预期是 **51~52 分**，不是大幅提升。val 与榜单的落差此前已出现过
（初赛 val +1.2pp 而榜单 -5 分），因此**本说明不对榜单涨幅作承诺**。

## 七、合规性声明

- **数据来源**：仅使用赛事官方提供的训练集（2000 组，1700 训练 / 300 验证）。
  经 md5 内容级审计，训练集、验证集与测试集**零重叠**。
- **测试集用途**：仅用于推理预测，未参与训练、未标注、未篡改、**未生成任何伪标签**。
- **预训练权重**：仅使用赛事明文允许的 Objects365 公开权重，未引入任何外部数据集。
- **无模型集成**：提交结果为**单一模型、单一权重**的输出。多尺度 TTA 属同一权重的推理增强，
  不属于规则第十一条(一)所禁止的「多个不同结构或训练阶段的模型进行简单集成」。
- **无人工干预**：全部检测框由模型自主推理产出；出包后仅执行程序化 `clamp[0,1]`。
- **离线完成**：训练与推理全程本地离线，未调用任何在线服务或 API。
- **模态说明**：本方案为**三模态（RGB + Infrared + Depth）**方案，输入为 5 通道。
